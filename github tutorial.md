##  add  ##
*** git add . *** 
. means all

if you want to add a specific file add file name with extension (filename.cpp)

*** git add filename.cpp ***

you can add multiple if you want

## commit ##

***git commit -m "name of commit"***

## Branching ##
*** git branch -M main ***

## add remote origin ##
*** git remote add {github url} ***


## Push ##

*** git push origin main***




Main flow of our github

1. git init (!bar e for one repo)
2. git add .
3. git commit -m "commit masssage"
4. git branch -M main
5. git remote add origin [github repo link/url]  *** 1 bar ***
6. git push origin main
